## Ship it, then automate it

I build backend systems and containerized platforms, then figure out how to deploy, monitor, and scale them without babysitting a terminal.

TypeScript and Python for the services. Docker and GitHub Actions for getting them out the door. Right now I'm pushing further into Kubernetes, cloud infra, and DevSecOps — closing the gap between "it runs on my machine" and "it runs."
