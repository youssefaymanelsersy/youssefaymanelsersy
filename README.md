## Building reliable systems, one deployment at a time

I’m an **aspiring DevOps Engineer** and Computer & Communication Engineering student at Alexandria University, interested in building reliable, automated, and scalable systems.

My work sits at the intersection of **DevOps, backend engineering, cloud infrastructure, and AI-powered applications**. I enjoy containerizing applications, building CI/CD pipelines, working with Linux and networking, and turning development workflows into repeatable deployments.

I’m currently focused on strengthening my skills in **Docker, Kubernetes, GitHub Actions, Linux, cloud infrastructure, observability, and DevSecOps** while continuing to build backend systems with TypeScript and Python.
